# §9 Conclusion（ドラフト v0.1 — 2026-09-02）

本研究は、推論基盤を変更できない商用コーディングエージェント CLI の上で、
セッション親和性をコスト最適化に使えるかを、機構測定、コストモデル、事前登録実験の
3段階で検討した。キャッシュ挙動の測定は、共有プレフィックス、resume、CLI 固定文脈、
実効 TTL、初回 resume の書き直しについて、クライアントから制御できる範囲とできない範囲を
切り分けた。ここが本稿の中心的な経験的貢献である。

7仕様・98対応対の評価では、write-scope 連結成分によるレーン継続 C は、毎回新規
セッション B に対して費用を削減しなかった。費用差の中央値は +5.5% で、H1 と20%削減基準は
不成立だった。一方で、時間比1.042と受入全通過率 B 100.0% / C 99.0% により、
時間と品質の非劣性ゲートは成立した。要約すれば、**遅くも粗くもならないが、安くもならない**。

この負の結果は「セッションを継続すべきでない」という一般則ではない。CT 型、すなわち
依存はないが write-scope が交差する形状では、C が14対すべてで高く、費用差中央値は
+50.6%だった。他の形状では効果は小さく混在した。したがって問題は親和性の有無ではなく、
文脈再利用の利得と過剰直列化の代償を、ワークロード形状ごとに選別できるかである。

また、コストモデルは7仕様中6仕様で大きさを許容誤差内に収めた一方、2仕様で符号を外し、
7仕様すべてで C の不利を過大評価する方向へ偏った。モデルは意思決定器として完成しておらず、
較正データの増加、E/W 境界の感度分析、非制御な初回 resume 状態の扱いが必要である。

次段階では、(1) CT 型を継続対象から外す admission rule、(2) 複数リポジトリ・言語・モデル・
CLI版での追試、(3) 実運用におけるワークロード形状の頻度推定を、現行データとは独立した
新しい事前登録研究として扱うべきである。適応スケジューラ D、RTK 型助言注入、RecursiveMAS は
本稿で測定していないため、本結果から有効性・無効性を主張しない。
