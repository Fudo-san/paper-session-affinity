# 事前登録: 非劣性マージン

> 作成: 2026-07-31 / status: **FROZEN v1.0**（2026-07-31 承認・凍結。本実験開始後の変更禁止）
> マージンは判断値である。導出根拠と弱点を隠さず書き、§8 Limitations に同旨を再掲する。

## 1. 品質マージン δ_q = 10pp【確定】

- 対象: 受入全通過率（spec×rep 単位の二値）の差（C − B）。
- 判定: 差の**片側90%CI の下限 > −10pp** で非劣性成立。
- 根拠（判断）: 通過率が 10pp 落ちると、失敗 run の人間による診断・修正・再実行コストが
  トークン削減益を食い潰す水準になる、という運用判断。
  - −5pp は本規模（3〜5仕様 × N反復）では検出力が足りず、実際の優劣に関係なく
    ほぼ常に「不成立」になる＝マージンとして機能しない。
  - −20pp は「5回に1回余計に壊れる」を許容することになり、「品質を犠牲にしない」
    という主張と両立しない。
- 弱点: 10pp は原理からの導出ではない。この恣意性は Limitations に明記する。

## 2. 時間マージン δ_time = 15%【確定】

- 対象: 壁時計時間の中央値の比 median(T_C) / median(T_B)。
- 判定: **比の片側CI（bootstrap BCa）上限 < 1.15** で非劣性成立。
- 根拠（判断）: レーン継続は write-scope 連結成分内を直列化するため一定の遅延は
  構造的に予測される（§4.2）。15% はその許容度。20% を超える遅延は、本研究の
  出発点である「時間をトークンで買う」並列化の利点を実質返上することになる。
- 弱点: 同上（判断値）。

## 3. 検出力不足時の扱い（事前に決めておく）

- 品質（二値・小標本）の非劣性検定は検出力が低い可能性が高い。
- CI が広く非劣性を**示せない**場合: 「品質低下の証拠はないが、非劣性も確立できなかった」
  と**そのまま**書き、中心主張を「費用削減（RQ1）＋時間非劣性（RQ2）」に縮退する。
  観測された通過率と件数は生のまま表で報告する。
- **やらないこと**: 非劣性が示せなかった事実の言い換え・隠蔽、事後的なマージン拡大。
